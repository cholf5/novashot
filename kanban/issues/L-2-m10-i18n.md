## 目标

UI 文案可翻译，zh-CN 首发（作者母语，也是截图工具的主要受众之一）。

## 子任务

1. resx 资源骨架 + `I18n` 取串 helper（Avalonia 资源字典或 resx 均可，先定方案再动手）。
2. 全量抽串：MainWindow/Overlay/工具环/样式面板/CompositionPanel/WindowPicker/托盘菜单 + S-1 设置页。
3. zh-CN 翻译首发；语言切换进设置页（S-1 完成则挂其分区，否则先 config 字段）。
4. key 一致性单测：所有 locale 的 key 集合与默认语言完全一致（CI 兜底）。

## 验收标准

- 无硬编码用户可见文案残留（grep 抽查）；zh-CN 切换即时生效，无需重启。

## 测试用例

- key 一致性单测；缺 key 回退默认语言逻辑单测。
