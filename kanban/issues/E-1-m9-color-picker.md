# E-1 M9 屏幕取色器

- **优先级**: P2 ｜ **复杂度**: M ｜ **开发者**: 待领取 ｜ **状态**: To Do
- **依赖**: 无（建议在 D-1 后做，同为捕获层小功能）
- **关联**: flameshot 招牌交互（放大镜取色 + 色值历史）；prtsc 已有 `EdgeColorExtractor`（像素访问路径可参考）

## 目标

flameshot 最显眼的交互：截图时鼠标处放大镜 + 实时色值，点击即取色。

## 子任务

1. 选框阶段按住某键（如 `C`）或独立工具进入取色模式：放大镜（如 11×11 像素放大 + 网格）跟随光标。
2. 浮签显示 HEX / RGB；点击复制色值并退出（或写入当前描边/填充色，设计时定，写进验收）。
3. 色值历史（会话内最近 N 个，面板可再取）。
4. 跨 DPI 缩放坐标取像素注意走 image 空间坐标（SkiaCanvas 三层坐标映射沿用 EditorViewModel 实现）。

## 验收标准

- 取色值与实际屏幕像素一致（DPI 缩放 125%/150% 下也正确）。
- 复制后任意输入框可粘贴 HEX。

## 测试用例

- 像素→HEX/RGB 格式化纯函数单测；放大镜采样区域计算单测。
- 真机冒烟：128 dpi 与 192 dpi 屏各取一次对比系统取色器。
