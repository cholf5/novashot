5. Prtsc.Core 保持 `net10.0`（无 Windows TFM），Win32 一律进 Prtsc.Platform.Windows。

### 本会话新做的关键设计决定
1. **Mosaic/Blur 是"采样型标注"而非原方案的"烤入位图 + 差分 Undo"**：`PixelEffectAnnotation` 持非拥有 `Document.Source` 引用，Render 时现场采样。Undo/移动/缩放白嫖既有命令 + BoxHandles，零位图差分代码。取舍：两效果重叠不叠加（后画者采样原始 Source，同 Flameshot）。**M6d 做裁剪、M8 CLI headless 导出时按此理解，不要走回烤位图路线**。
2. **EditorState 改动不进 Undo**（延续样式不进栈决定）；`OnCompositionStateChanged` 里 `NotifyMutated()` + 刷新 `ContentWidth/Height`。
3. **样式/合成默认值即"无效果"**：所有新效果默认关，保证老路径回归锚点成立。
4. **编辑文本中不导出**（导出走 skipAnnotation 逻辑会漏字，直接禁掉）。

## 4. 关键发现（API 坑，实测验证过）

### SkiaSharp 3.119.4
- **枚举名是 `SKShaderTileMode`**（`SKTileMode` 不存在；可用 PowerShell 在 DLL 字节里搜名字确认，反射 `GetTypes` 会因依赖加载失败报错）。
- **sampling 重载只在 `DrawImage` 上**：`DrawBitmap(bitmap, src, dest, SKSamplingOptions)` 编译不过。要控制采样：`SKImage.FromPixels(bmp.Info, bmp.GetPixels(), bmp.RowBytes)` 非拥有包装后 `DrawImage`。
- `SKSamplingOptions` 无静态 `Linear`：用 `new SKSamplingOptions(SKFilterMode.Linear, SKMipmapMode.None)`；`default(SKSamplingOptions)` = 最近邻（Mosaic 放大靠它）。
- `SKColor` 不是编译期常量 → record 主构造默认参数用 `SKColor?` + Effective 属性模式。
- `SKBitmap.Save(Stream, int?)` 已废弃 → 一律 `SKImage.Encode`。
- **xUnit 里 `GetPixel` 越界会让测试主机 0xC0000005 崩溃**（不是托管异常）——写光栅测试先算好位图尺寸，探针坐标别越界。

### Avalonia 12.1
- **brush 已删 `MappingMode`**：线性渐变的相对/绝对映射由端点 `RelativeUnit` 决定。
- `ToggleButton` 在 `Avalonia.Controls.Primitives`（code-behind 忘了就 CS0246）。
- `RelativePoint`/`RelativeUnit` 在 `Avalonia` 根命名空间。
- 旧坑仍有效：`Key.Enter == Key.Return` 同值；AVLN5001 忽略等。

### 测试侧
- `Assert.Equal(float, float, int)` 与 decimal 重载对 byte 有二义性 → 先 cast float（或直接 `Math.Abs` 差值断言）。
- Skia 预乘舍入：均匀色模糊后允许 ±2 容差。

## 7. 风险与注意事项

**易跑偏的方向**
- 不要把 Mosaic/Blur 改回烤位图（见 §3 设计决定 1）。
- 不要在 Prtsc.Core 引 Avalonia（它是 net10.0 纯库；剪贴板/文件对话框都是 App/Platform 层的事）。
- `SkiaCanvas` 的坐标分三层：DIP（控件）/ content（含 padding）/ image（标注）。动视口或映射时三层都要过一遍，漏一层就会出现"选中框错位"类 bug。
- 合成面板的每个 setter 都是 `with` 重建 state → `OnCompositionStateChanged` → `NotifyMutated`。别在面板外直接改 `EditorState` 的成员（它不可变，也改不了），保持同一通路。
- `ImageExporter.Render` 的画布是 `SKAlphaType.Premul` + Background.None 时角落 alpha=0——JPEG 编码会变黑，M6c 做 Auto-copy 转格式时要记得垫底色或提示。

**已验证不必重复调查**：24 预设全部可解析；默认 state 与裸渲染逐像素一致；PNG/JPEG/WebP 编解码往返；SkiaSharp 原生库在 xUnit 进程可用；Avalonia 12 StorageProvider 文件对话框 API（`SaveFilePickerAsync` + `FilePickerSaveOptions`）可用。
