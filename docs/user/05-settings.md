# 05 设置中心

入口：托盘 →「设置…」、主窗口 `⋯` → 设置。整窗是**草稿语义**：改完点「保存」才生效，点「取消」全部丢弃。

六个分区：

## 常规

| 项 | 说明 |
|---|---|
| 开机自启 | Windows 写注册表 Run；macOS 写 launchd LaunchAgent；Linux 写 XDG Autostart |
| 启动时最小化到托盘 | 开机自启常配这一项 |
| 关闭按钮隐藏到托盘 | 关窗不退出进程；退出请用托盘 → 退出 |
| 截图完成通知 | Windows toast；关掉只留状态栏提示 |
| 启动时检查更新 | 未打包运行（源码 `dotnet run`）恒静默 |
| 更新 feed 地址 | Velopack feed 根地址，**必须能让 `releases.win.json` 直接可达**，例如 `https://github.com/<owner>/<repo>/releases/latest/download/`（填 GitHub 仓库主页或 `/releases` 页面会 404）；留空 = 永不检查 |
| 语言 | 跟随系统 / English / 简体中文，切换后立即全窗口生效 |

## 热键

三行录制器：全屏截图、区域截图、窗口截图。

- 点某一行 → 按下组合键即录入；`Esc` 取消本次录制
- 支持不带修饰键的单键（如 `PrintScreen`）
- 纯修饰键、`NumPad` 组合会被拒绝；组合重复会给出提示
- **保存那一刻**才真正重注册（先注销旧、再注册新），中途取消不影响当前热键

## 快速保存

| 项 | 说明 |
|---|---|
| 保存文件夹 | `Ctrl+Q` 的目标目录；留空 = `~/Pictures/Prtsc`（自动创建） |
| 文件名 | 三种模式：时间戳 / 按天 / 递增序号（示例见界面提示） |

## 导出

| 项 | 说明 |
|---|---|
| 默认格式 | PNG（无损）/ JPEG（更小）；决定保存对话框的默认扩展名 |
| JPEG 质量 | 1–100，默认 95（仅 JPEG 生效） |
| 包含背景 | 关掉 = 导出时去掉合成背景（等同只导图片本体） |
| 导出后复制到剪贴板 | 勾选时每次导出都会顺带写入剪贴板（此路径不重复弹通知） |

## 编辑器默认值

这里编辑的是「上次使用的画布参数」——每次在编辑器 Canvas 面板里改动都会回写到这份配置，重启后仍保持。

- 画布：Padding、圆角、阴影、输出比例、是否显示背景、背景色（含自定义 hex）、内衬、自动背景色、内衬底色、形状圆角
- 边框：开关、粗细、颜色、不透明度、位置（外/中/内）
- **工具坞按钮**：15 个工具的可见性勾选框
  - `选择` 恒显示且不可取消（必须有默认工具）
  - 全选等于「默认全显示」（将来新增工具会自动出现）
  - **隐藏不等于禁用**：被隐藏工具的热键依然可用

## 捕获

| 项 | 说明 |
|---|---|
| 包含鼠标光标 | 仅 Windows 生效（窗口与全屏捕获都走 WGC）；mac/Linux 忽略 |
| 默认延时 | 无 / 3 秒 / 5 秒。作用于热键与托盘捕获，以及托盘「延时截图」菜单；倒计时期间按任意截图热键可取消 |

## 托盘菜单一览

显示 Prtsc ｜ 全屏截图 / 区域截图 / 窗口截图 ｜ 延时截图（3s / 5s）｜ 截图启动器… ｜ 截图历史… / 云上传设置… ｜ 设置… ｜ 退出

托盘图标悬浮提示里带版本号，方便确认装的是哪一版。

## 配置文件

设置项几乎都能在 GUI 里改；需要批量部署或排查时直接编辑 `config.json`（Windows `%AppData%\Prtsc\`，macOS `~/Library/Application Support/Prtsc/`，Linux `~/.config/Prtsc/`），保存后重启生效。字段与界面的对应关系见 [README 的配置一节](../../README.md#配置文件与数据目录)。
