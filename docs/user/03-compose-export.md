# 03 合成与输出

## 顶栏按钮

| 按钮 | 快捷键 | 作用 |
|---|---|---|
| ← Back | — | 回到捕获起始界面（当前编辑内容丢弃，已保存的除外） |
| ↺ / ↻ | `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| Save | `Ctrl+S` | 导出对话框（PNG / JPEG / WebP） |
| Copy | `Ctrl+C` | 复制合成结果到剪贴板 |
| `⋯` | — | 快存、上传、贴图、导入图片、历史、云设置、设置 |

**导出格式由扩展名决定**：保存对话框选 `*.png` / `*.jpg|*.jpeg` / `*.webp`，默认扩展名跟随「设置 → 导出 → 默认格式」。JPEG 质量在设置里调（1–100，默认 95）。

## 合成参数（Canvas 面板）

参数逐项说明见 [02 标注 § Canvas 面板](02-annotate.md#canvas-面板合成外观)。三个行为要知道：

1. **即时预览**：任何改动立即反映在画布上，不需要「应用」按钮。
2. **会被记住**：「设置 → 编辑器默认值」显示的就是上次使用的值，下次进编辑器自动套用（重启也保持）。
3. **只影响导出，不改原图**：合成是渲染阶段的事，源位图始终是完整的原始截图；裁剪也是非破坏的。

透明背景（Background = None）在画布上显示棋盘格，导出 PNG 时这些区域是真透明；导出 JPEG 时透明会被拍平（JPEG 无 alpha 通道）。

## 三种落盘方式

| 方式 | 入口 | 行为 |
|---|---|---|
| 导出对话框 | `Ctrl+S` / Save 按钮 | 选目录与格式，可改文件名 |
| QuickSave | `Ctrl+Q` / `⋯` 菜单 | 不弹框，直接存到「设置 → 快速保存」的目录 |
| 上传 | `Ctrl+U` / `⋯` 菜单 | 上传到云并复制链接（见 [04](04-cloud-library.md)） |

**QuickSave 目录与命名**

- 目录：设置 → 快速保存 → 文件夹；留空 = `~/Pictures/Novashot`（自动创建）
- 命名模式：与导出/CLI 共用同一套
  - `timestamp`：`novashot_2026-11-10_18-25-30.png`
  - `date`：`novashot_2026-11-10.png`，同一天多张自动加 `_1`、`_2`…
  - `increment`：`novashot_001.png`、`novashot_002.png`…（扫描目录取最大号 +1）

导出成功后按设置弹系统通知（Windows）；「设置 → 常规 → 截图完成通知」可关。

## 剪贴板

- **复制（写）**：同时放 `CF_DIBV5` + `CF_DIB` + 注册格式 `PNG`。PNG 让只认 PNG 字节的读者（Figma 等）也能拿到，且保留透明；像素超过约 400 万时跳过 PNG（避免 UI 卡顿），此时按 DIB 路径粘贴仍可用。
- **粘贴（读）**：依次尝试 `DIBV5` → `DIB` → `PNG`，解不动就继续下一个候选；四种格式（PNG/JPEG/WebP/BMP/GIF 文件路径如 HDROP、剪贴板位图）都能进编辑器。
- 与 Word / 微信 / Chrome / Electron 应用互通；若某个应用只认自己的私有格式，请改用「导入图片」（`Ctrl+O`）。

## 贴图（Pin）

`Ctrl+P` 或 `⋯` → 贴图：把当前合成结果贴成一块置顶小窗。

- 拖动移动；滚轮缩放（步长 10%，按住 `Ctrl` 变 25%）
- **双击关闭**；也可按 `Esc` 关闭
- 拖动时会弹一条临时提示条，2 秒后自动隐藏

## 导入本地图片

`Ctrl+O` 或 `⋯` → 打开图片文件：选一张本地图片直接进编辑器（等同一次截图），默认过滤常见图片格式，也可切「所有文件」让解码器自己判断。

## 快捷操作总表

| 快捷键 | 作用 |
|---|---|
| `Ctrl+S` | 导出对话框 |
| `Ctrl+Q` | QuickSave |
| `Ctrl+C` / `Ctrl+V` | 复制到剪贴板 / 从剪贴板粘贴新图 |
| `Ctrl+U` | 上传 |
| `Ctrl+L` | 打开 Library |
| `Ctrl+P` | 贴图 |
| `Ctrl+O` | 导入图片文件 |
