# 04 云上传与历史

## 配置云渠道

入口：编辑器 `⋯` → 云上传设置，或托盘 →「云上传设置…」，或设置页里的云分区。

### Cloudflare R2（S3 兼容）

1. Cloudflare → R2 → Manage API Tokens，建一个可写该桶的 Token，记下 **Account ID**
2. 在 Prtsc 里填：Account ID、Bucket、Access Key ID、Secret Access Key
3. 可选：**公开访问地址**（如 `https://img.example.com`）——填了才会生成可分享链接；不填则上传成功但没有 URL
4. 可选：**上传目录**——对象 key 前缀，用来按目录归档

### Google Drive

1. Google Cloud Console 建 OAuth「桌面应用」客户端
2. 用离线授权换一个 `refresh_token`
3. 在 Prtsc 里填：Client ID、Client Secret、Refresh Token
4. 可选：目标文件夹 ID（留空 = 我的云端硬盘根目录）

### 测试连接

点「测试连接」会真的发一次请求：R2 = `HeadBucket`，Drive = token 刷新。失败会给出可读原因（凭据缺失、403、网络等）。凭据不完整时会先提示缺哪个字段。

> 凭据以**明文**保存在本机 `config.json` 里，不会上传到任何第三方（只用于直连你配置的服务）。共享机器上请注意文件权限。

## 上传与自动上传

| 方式 | 触发 |
|---|---|
| 手动 | `Ctrl+U` / 工具栏上传按钮 / `⋯` → 上传 |
| 自动 | 云设置里勾「保存后自动上传」，导出/快存时会顺带传一份 |

- 上传成功后链接会**自动复制到剪贴板**，状态栏与系统通知也会给反馈
- 没有任何上传渠道（Provider = 不上传）时，工具栏上传按钮不可用
- 上传只是附加动作：**本地文件照常落盘**，云端失败不影响本地结果

## Library（截图历史）

入口：`Ctrl+L`、托盘 →「截图历史…」、编辑器 `⋯` → 历史。

- 记录内容：文件名、尺寸、体积、创建时间、缩略图、本地路径、远程链接（若上传过）
- 搜索框按文件名过滤
- 可用操作：
  - **打开图片**：用系统看图工具打开本地文件
  - **复制链接**：仅上传过的记录有链接；没有链接的记录会提示
  - **复制路径**：复制本地文件路径
  - **删除**：弹确认框；若该记录有本地文件，确认框里会多一个「同时删除磁盘上的图片文件」勾选项
- `Delete` / `Backspace` 也能触发删除（走同一个确认框）

### 删除策略（重要）

| 场景 | 结果 |
|---|---|
| 不勾「同时删除文件」 | 只删 Library 记录，磁盘图片保留（默认，最安全） |
| 勾了 | 记录与磁盘文件都删 |
| 文件已被外部移走/删掉 | 静默只删记录，不报错 |
| 文件被占用删不掉 | 记录已删（不回滚），状态栏提示「记录已删除，但文件未能删除」，日志留痕 |

> Library 只是索引，删记录不会去动你别的目录里的图片。

## 数据保存在哪

Windows `%AppData%\Prtsc\`、macOS `~/Library/Application Support/Prtsc/`、Linux `~/.config/Prtsc/`：

- `library.json`：历史索引
- `Thumbs/thumb_<id>.png`：缩略图
- `config.json`：含云凭据

想彻底重置历史：退出程序，删掉 `library.json` 与 `Thumbs/`，再启动即可。
