# 01 捕获

## 三种捕获

| 方式 | 默认热键 | 入口 |
|---|---|---|
| 全屏（整个虚拟桌面） | `PrintScreen` | 主窗口命令列表 / 托盘「全屏截图」 / CLI `prtsc full` |
| 区域 | `Ctrl+PrintScreen` | 主窗口 / 托盘 / CLI `prtsc region` |
| 窗口 | `Ctrl+Shift+PrintScreen` | 主窗口 / 托盘 / CLI `prtsc window` |

> 多屏时「全屏」= 所有显示器拼成的虚拟桌面（含负坐标区域），不是光标所在那一个屏。

## 区域选框（overlay）

截图后屏幕会盖一层暗色遮罩，拖动画框，然后：

| 操作 | 效果 |
|---|---|
| 拖动框内 | 移动选框 |
| 拖 8 个手柄 | 缩放；`Ctrl` 吸附八方向（含对角），`Shift` 正交约束 |
| `Enter` | 确认进入编辑器（**没有选框时 = 整屏**） |
| `Esc` | 第一次清除选框，再按一次退出捕获 |
| `C` | 切换取色模式：放大镜 + 网格 + HEX/RGB 浮签，点击即复制色值并写入当前描边色 |

**跨屏选框**：可从 A 屏按下滑到 B 屏，选框在两块屏上各自按本屏缩放渲染成连续的一块；确认后按物理像素拼成一张图。工具环与尺寸标签挂在选框中心所在的那块屏。

## 窗口选择器

窗口捕获会弹出窗口列表：

- 每行带 96×54 实时缩略图（抓不到时退回占位首字母），标题、进程名可见
- 双击某行或选中后点「确定」即捕获该窗口；`Esc` 或「取消」放弃，「刷新」重扫列表
- 最小化窗口会标注状态，捕获结果可能是黑帧（系统限制，非 bug）

## 延时截图

用途：需要先把菜单、悬停提示、下拉框展开再拍。

- 托盘 →「延时截图」→ 3 秒 / 5 秒（全屏）
- 设置 → 捕获 → 默认延时：`0 / 3 / 5` 秒；此处设的值会作用于**不带 `--delay` 的** CLI 与托盘捕获
- 倒计时期间屏幕角落显示角标；**再按任意截图热键即可取消本轮**（状态栏提示「已取消」）
- 角标本身不会进截图（抓帧在角标关闭后 250ms 才发生）

## 截图启动器

托盘 →「截图启动器…」：不需要先记住热键，一个窗口里选定

- 捕获范围：全屏 / 区域
- 区域几何：`X / Y / W / H`（物理像素，越界自动钳制到屏幕内）
- 延时秒数
- 点「开始截图」后走与热键完全相同的路径

## 捕获小贴士

- **Windows**：设置 → 捕获 →「包含鼠标光标」控制是否把光标画进画面（仅 Windows 生效）
- **macOS**：首次捕获需要在 系统设置 → 隐私与安全性 → 屏幕录制 里授权；未授权时会直接给出中文指引
- **Linux**：仅 X11 / XWayland 会话；Wayland 原生会话未支持（见 [07 故障排查](07-troubleshooting.md)）
- 捕获成功后会按设置弹出系统通知（Windows），失败只在状态栏与日志里提示
