# 02 标注

编辑器布局：中间画布、底部工具坞、右侧面板（Style / Canvas 两页）、顶栏（撤销/重做、Save、Copy、`⋯` 菜单）。

## 工具与热键

| 热键 | 工具 | 说明 |
|---|---|---|
| `V` | 选择 | 点选已有标注，拖动移动，拖 8 手柄缩放；`Delete` 删除 |
| `R` | 矩形 | 拖出空心矩形，描边宽度走样式面板 |
| `E` | 椭圆 | 同上 |
| `A` | 直线箭头 | 端点箭头，可用 `Ctrl` 约束角度 |
| `O` | 曲线箭头 | 拖出后可见控制点手柄，可再拖控制点调整弯曲 |
| `L` | 直线 | |
| `T` | 文字 | 点击落点即弹输入框，`Enter` 提交、`Esc` 取消 |
| `N` | 序号 | 自动编号，`Ctrl+滚轮` 改序号；删除后新序号优先复用最小空缺 |
| `S` | 聚光灯 | 选区外压暗 |
| `P` | 铅笔 | 手绘自由曲线 |
| `H` | 荧光笔 | 半透明宽笔触 |
| `M` | 马赛克 | 区域内像素化 |
| `B` | 模糊 | 区域内高斯模糊 |
| `I` | 反色 | 区域内反色，区域外像素零改动 |
| `X` | 裁剪 | 非破坏裁剪；应用后仍可拖 8 手柄 reshape，配合比例预设 |

> 在文字输入框里打字时，字母热键不会抢输入——只有离开输入态（`Esc` 或提交）才生效。

## 通用操作

| 操作 | 效果 |
|---|---|
| `Ctrl+滚轮` | 调整描边宽度（文字工具下调字号，效果工具下调强度） |
| `Ctrl+Z` / `Ctrl+Y` / `Ctrl+Shift+Z` | 撤销 / 重做（50 步） |
| `Delete` / `Backspace` | 删除当前选中标注 |
| `Esc` | 取消正在拖的标注 → 取消选中 → （再按）退出编辑器 |
| 拖拽中按 `Esc` | 放弃这一笔，不产生标注 |
| 拖拽时按住 `Ctrl` | 角度吸附八方向（含对角） |
| 拖拽时按住 `Shift` | 正交约束 |
| `Ctrl+滚轮`（序号工具） | 改序号数字，无需重画 |

## Style 面板（选中/绘制样式）

- **颜色**：8 个预设色块（4×2）；点选后立即成为当前描边色，选中环标在正在用的那个上
- **取色历史**：本次会话最近 10 个取到的颜色（来自 overlay 的 `C` 取色），点一下即设为描边色；没有历史时整行隐藏
- **描边宽度**：1–16 px
- **字号**：12–72（仅文字工具时出现）
- **当前选中**：显示选中对象的类型（矩形/曲线箭头/文字…）

## Canvas 面板（合成外观）

不走「选中对象」，而是整张画布的合成参数，改动即时预览、并会被记住作为下次的默认值：

| 分组 | 控件 |
|---|---|
| 背景 | `None` / `Solid` / `Gradient` 三态；24 个渐变预设 + 纯色预设；`A` 按钮 = 自动取图片边缘主色 |
| 边框（Frame） | Padding 0–96、Corner radius 0–48、Shadow 开关 + 4–48 |
| 边框描边（Border） | 开关 + 1–12 px + 外侧/居中/内侧 + 颜色板 |
| 内衬（Inset） | 开关 + 2–24 + 颜色板 |
| 输出比例 | 自动 / 1:1 / 4:3 / 3:2 / 16:9 / 5:3 / 9:16 / 3:4 / 2:3 |

**透明背景**：选 `None` 时画布上会铺棋盘格提示「这里是透明的」，棋盘格只是编辑器提示、不会画进导出图。想要无留白就把 Padding 拖到 0。

## 裁剪（X）与比例

1. 选 `X` 拖出裁剪框，或在比例下拉里选预设
2. 应用后裁剪框保持可见（暗遮罩 + 白框），可以继续拖 8 手柄微调
3. 拖过对边会停住（最小 4 px），拖到画布外会被钳回图像内
4. 重新拖一个新框会覆盖旧框；`Esc` 恢复本次拖拽开始前的框
5. 裁剪是非破坏的：原图不丢，随时可以重新拉框

## 小贴士

- 工具坞可以在 设置 → 编辑器默认值 → 工具坞按钮 里裁剪（`Select` 恒显示）；**隐藏 ≠ 禁用**——被隐藏的工具热键仍然可用
- 顶栏 `⋯` 菜单里有检查更新、设置、打开历史等入口
- 编辑器宽度/高度会随参数变化，窗口尺寸与上次的画布参数都会持久化
