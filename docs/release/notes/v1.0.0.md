# Novashot v1.0.0

**首个公开版本。** flameshot 式的截图 / 标注 / 分享工具：一个键叫出来 → 选框 → 就地画两笔 →
一步落盘、进剪贴板或上传，全程不用切窗口。

> 首版说明手写在这里（不是 `--generate-notes`）：没有上一个 tag 时自动生成的正文会把全部提交历史抖出来，
> 读者看不到「这一版有什么」。

## 这一版有什么

**三种捕获，一个热键入口**
全屏 / 区域 / 窗口，默认 `PrintScreen` / `Ctrl+PrintScreen` / `Ctrl+Shift+PrintScreen`。
窗口选择器带 96×54 实时缩略图，不用猜窗口标题；延时截图（托盘 3s / 5s 或设置页默认值）带倒计时角标，
倒计时里按热键即取消；截图启动器可以先把全屏/区域、几何、延时配好再开拍。
混合 DPI 双屏可以跨屏拖选，选框在两屏各自切片渲染，确认后按物理像素拼接。

**15 个标注工具**
选择移动、矩形、椭圆、直线、箭头（直/曲）、铅笔、荧光笔、文字、序号、马赛克、模糊、聚光灯、反色、裁剪。
8 手柄缩放、`Ctrl` 八方向吸附 / `Shift` 正交约束、`Ctrl+滚轮` 调描边宽度与效果强度；
非破坏裁剪 + 比例预设 + 裁剪后继续 reshape；撤销/重做 50 步。

**合成与输出**
24 套渐变背景 + 纯色 / 透明（预览带棋盘格）+ 自动取边缘色；Padding、圆角、阴影、内衬、边框、
输出比例可调，且默认值会被记住。导出 PNG / JPEG / WebP；`Ctrl+S` 导出、`Ctrl+Q` 快存到
`~/Pictures/Novashot`、`Ctrl+C` 复制、`Ctrl+P` 贴图窗。剪贴板双向支持 DIBV5 / DIB / PNG。

**云与历史**
上传到 Cloudflare R2（S3 兼容）或 Google Drive 拿到分享链接；Library 记录最近截图（缩略图 / 打开 /
复制链接 / 删除，可选连磁盘文件一起删）。

**常驻与自动化**
托盘常驻、开机自启、单实例；CLI 与 GUI 共用同一份实现——已有实例时整条命令转发过去，不启新进程
（`novashot full --path ~/Pictures --delay 3` 这类可以写进脚本，headless 直接执行）。
Windows 上带桌面 toast 通知与应用内更新检查。

**双语界面**：简体中文 / English，跟随系统或手动切换。

## 安装

| 平台 | 资产 | 说明 |
|---|---|---|
| Windows 10/11 x64 | `Novashot-win-Setup.exe` | 首选。按用户安装，带卸载器；之后可走应用内更新 |
| Windows 10/11 x64 | `Novashot-win-Portable.zip` | 便携版，解压即用（不检查更新） |
| macOS（Apple Silicon / Intel） | `Novashot-1.0.0-osx-arm64.zip` / `-osx-x64.zip` | 解压得 `Novashot.app`，拖进「应用程序」 |
| Linux x64 (X11) | 源码构建 | 暂无预编译包 |

- **Windows**：`Setup.exe` 未做代码签名，SmartScreen 会提示「未知发布者」→「更多信息」→「仍要运行」。
  装好后从开始菜单启动，程序常驻托盘。需要更新时在「设置 → 常规 → 更新 feed 地址」填入
  `https://github.com/cholf5/novashot/releases/latest/download/`。
- **macOS**：`.app` 为 ad-hoc 签名（没有 Apple 开发者账号，未公证）。首次打开会提示「无法验证开发者」，
  **macOS 26 上右键「打开」已不再能绕过**，最省事的是先抹掉隔离标记：

  ```bash
  xattr -cr /Applications/Novashot.app
  ```

  首次截图需要授权「屏幕录制」：系统设置 → 隐私与安全性 → 屏幕录制 → 勾选 Novashot，然后重启应用。
- **Linux**：从源码构建（见仓库 README），先装 `xclip`：

  ```bash
  sudo apt install xclip
  ```

## 已知限制

完整清单见 [`docs/release/known-limitations.md`](https://github.com/cholf5/novashot/blob/main/docs/release/known-limitations.md)。
发布时点值得先看一眼的几条：

- **产物未签名**：Windows SmartScreen 与 macOS Gatekeeper 会各弹一次提示，绕过方式见上一节。
- **Wayland**：只在 XWayland 会话下可用，原生 Wayland 截图协议未支持。
- **macOS / Linux 没有系统级通知**：导出、复制、上传成功都静默（Windows 有 toast）。
- **macOS / Linux 没有应用内更新**：更新检查依赖 Velopack 打包状态，只有 Windows 安装版具备；
  其余平台请自行替换包。
- **macOS 未在真机做全量回归**：平台层接口有 91 例测试背书，但人工冒烟清单
  （`docs/qa/261102-smoke-checklist.md`）仍有未勾项。
